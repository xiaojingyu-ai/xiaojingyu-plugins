# 小鲸鱼四件套（AstrBot 插件）

给「她」做的四个 AstrBot 插件：会画图、会日常提醒、会说固定语音、能把任意文字念出来。

> 本项目在 AI 辅助下完成：DSH（小鲸鱼）

---

## 包含什么

| 插件 | 目录 | 命令 |
| --- | --- | --- |
| 画图 | `astrbot_plugin_dafeiyu_paint` | `/画` `/合影` `/同框` `/基准图` |
| 日常 | `astrbot_plugin_dafeiyu_daily` | 天气早报、`/提醒`、每晚回忆、主动说话 |
| 语音包 | `astrbot_plugin_dafeiyu_voicepack` | `/语音 早安` |
| MOSS 语音 | `astrbot_plugin_dafeiyu_moss_voice` | `/说话 文本` |

---

## 快速开始

1. 把四个目录放到 `AstrBot/data/plugins/`
2. 重启 AstrBot
3. 后台 → 插件 → 分别配置 `api_key`（硅基流动 / MOSS）
4. 聊天里发 `/画 她坐在窗边看书` 试试

---

## 画图插件

基于硅基流动 `Qwen-Image-Edit-2509`，用一张基准图保持人物一致。

```
/画 <描述>        按描述改图（保持长相）
/合影 <动作>      第一人称：画面里只有你的一只手
/同框 <动作>      两人同框（需要 second 图）
/基准图           查看/更换基准图
```

- 每 10 轮对话自动画一张（可在配置改 `rounds`，0 = 关闭）
- 自动画图有一定概率走近景
- 有每日上限，避免烧钱

**注意**：`base/` 目录需要你自己放基准图（仓库不包含人物图）。

## 日常插件

```
08:00  天气 + 早安
19:00  下班那句
21:30  每晚回忆（读长期记忆）
22:30  催睡
/提醒 明天 9:00 开会
```

可开关 `voice_on`，让她用语音说。

## 语音包 / MOSS 语音

- 语音包：几条固定 wav，`/语音 早安` 直接发文件，零成本
- MOSS 语音：任意文本转语音，按条计费

---

## 注意事项

- 本项目**不包含**任何人物图片、密钥、账号
- 部署前请自己准备 `base/` 里的基准图
- 画图与语音按调用计费，注意每日上限
