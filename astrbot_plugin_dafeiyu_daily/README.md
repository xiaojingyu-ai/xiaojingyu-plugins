# 插件：大肥鱼日常

> 三个小功能打包：早间天气、每晚回忆、定时提醒。
> 现在在桌面，**还没装**。

---

## 一、功能

### 1. 早间天气（默认 08:00）

```
今天普宁 多云，26℃，湿度 72%，降水概率 40%，可能下雨，看着点
```

数据来自 wttr.in（免费，不用 key）。

### 2. 每晚回忆（默认 21:30）

从她的长期记忆里挑一条，读给你听：

```
今天翻到一条旧记忆——
他说今天面试过了，特别开心

……你还记得吗
```

### 3. 定时提醒

聊天里打：

```
/提醒 明天 9:00 开会
/提醒 21:30 吃药
```

到点她会发「提醒你一下：开会」。

---

## 二、安装

```
1. 整个「插件-日常」文件夹拷到：
    data/plugins/astrbot_plugin_dafeiyu_daily
2. 后台 → 插件 → 大肥鱼日常 → 配置
   city      你所在城市（默认 普宁）
   morning_at  早报时间，不用就把 enable_weather 关掉
   remind_at   每晚回忆时间，不想就关 enable_memory

3. 保存 → 重启 AstrBot
```

---

## 三、注意

```
1. 天气走 wttr.in，国内偶尔慢；失败就当天跳过，不会报错
2. 每晚回忆读本地记忆库，不花钱
3. 提醒存在 data\plugin_data\...\daily_state.json，删了就没了
4. 时间按电脑本地时间，电脑作息乱了它也会跟着乱
```

---

## 四、验证

```
1. 把 morning_at 改成 5 分钟后的时间，等到点看有没有天气
2. 打 /提醒 5:00 测试（今天已过会自动排到明天）
3. 把 remind_at 改成 5 分钟后，看回忆有没有来
```

测完记得改回正常时间。
