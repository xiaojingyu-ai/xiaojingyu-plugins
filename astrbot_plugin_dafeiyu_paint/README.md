# 插件：大肥鱼画图（v2.0）

> 用硅基流动生成插画。核心是 **Edit 保持同一张脸**，换姿势/表情/场景/衣服。

---

## 一、准备

1. 硅基流动注册 + 实名，拿 API Key（`sk-` 开头）
2. 余额 ≥ 1 元（Edit 约 0.3 元/张，Turbo 约 0.1 元/张）

## 二、安装

```
把整个文件夹拷到：
 data/plugins/astrbot_plugin_dafeiyu_paint

后台 → 插件 → 大肥鱼画图 → 配置 api_key → 保存 → 重启 AstrBot
```

`base\` 文件夹必须跟着一起拷（里面是基准图，决定她长什么样）。
现在里面只有一张 `base3.png`（白毛衣・长发）。想换形象就替换它，或者再放几张（随机挑）。

`base_old\` 是旧的两张 Q 版图，插件不会用，留着当备份，可以不拷。

## 三、怎么用

```
/画 让她趴在窗台上          按你说的改（Edit，0.3 元）
/画 换成水手服              换成水手服
/画 她抱着布丁 文字：生日快乐   图片底部叠加一行白字
/基准图                     显示基准图文件夹路径
```

自动：每 10 轮自己画一张（0.3 元），30% 用聊天内容当场景，70% 抽池子。

## 四、上限

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `rounds` | 10 | 每多少轮自动画；0 = 关闭 |
| `daily_cap` | 3 | 自动每天最多几张 |
| `manual_cap` | 10 | 手动 /画 每天最多几张 |
| `steps` | 30 | Edit 步数 |
| `cfg` | 4 | Edit 的 CFG |

## 五、池子在哪改

`main.py` 开头的列表：

```
LOOK     固定外貌
NEGATIVE 负面词
POSES    姿势 22 条
FACES    表情 10 条
SCENES   场景 20 条（家里 + 恋爱感）
OUTFITS  衣服 8 套
MOODS    气氛 6 条
```

改引号里的中文即可，别动逗号和引号。

## 六、常见问题

```
没出图       看日志：key 错 / 余额不足 / 被审核拦
脸变了       一次改太多；改成一次只改一处
基准图没生效  确认 base\ 在插件目录里，且文件名是 .png/.jpg/.webp
```
